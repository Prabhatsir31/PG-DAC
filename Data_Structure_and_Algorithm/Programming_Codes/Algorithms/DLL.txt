================================

1. STRUCTURE OF NODE:
   Define a Node with:
      - data (int)
      - prev (Node)
      - next (Node)

2. CREATE DOUBLY LINKED LIST CLASS:
   - Initialize:
       head = null

3. INSERT AT BEGINNING:
   a. Create a new node with data.
   b. If head is null:
        - head = new node
   c. Else:
        - new node.next = head
        - head.prev = new node
        - head = new node

4. INSERT AT END:
   a. Create a new node with data.
   b. If head is null:
        - head = new node
   c. Else:
        - Traverse till last node (tail)
        - tail.next = new node
        - new node.prev = tail
