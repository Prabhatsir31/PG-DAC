5. Why enum?
    Represents named constants for better code readability.
    Replaces magic numbers.
        enum Day { Sun, Mon, Tue }

6. Why const?
    Declares a constant value that cannot be changed.
    Value must be assigned at declaration.
        const float PI = 3.14f;

 7. What is a struct?
    A value type similar to class but stored on the stack.
    Useful for small data models.
    Cannot inherit from other classes.


8. var – Declare and Initialize in One Line:
    var x = 10;     // Compiler infers type as int
    Must be initialized at the time of declaration.

9. Can I Modify Data Type After Declaring var?
    ❌ No. Once declared with var, the type is fixed.
    var x = 10;    // x is int
    x = "Hello";   // ❌ Compile-time error

10. dynamic Example:
    dynamic a = "hello";
    a = 5;    // ✅ Valid. Runtime-type checked

11. Parent of enum:
    System.Enum (abstract class)

12. Parent of Primitive Types:
    All value types (like int, float) derive from System.ValueType, which in turn derives from System.Object.
    int → ValueType → Object

13. Everything Derives from Object:
    Yes, in C#, every type (value or reference) ultimately inherits from System.Object.

14. DateTime is a Struct?
    Yes, DateTime is a value type (struct).

15. int a = new int(); Explanation:
    Initializes a to the default value of int
    int a = new int();  // a = 0

16. Can Programmer Write No-Args Constructor in struct?
    ❌ No. In .NET, you cannot define a parameterless constructor in a struct. The compiler provides a default one.

17. Struct Constructor Must Initialize All Members?
    Yes. If you define a custom constructor, it must initialize all fields.

18. What Can Be Overridden in struct?
    Structs can override:
    ToString()
    Equals()
    GetHashCode()
But they cannot inherit, so no base class methods (except from object) can be overridden.

19. What is Method Hiding?
    When a derived class defines a method with the same name as the base class method, it hides the base method.

    Use new keyword:
        class Base {
            public void Show() => Console.WriteLine("Base");
        }

        class Derived : Base {
            public new void Show() => Console.WriteLine("Derived");
        }

20.  Why Constructor?   
    A constructor is a special method that runs automatically when an object of a class is created. It is used to:
    Initialize data members (like setting default values).
    Ensure the object starts in a valid state.
    It has the same name as the class and no return type.
    class Person {
        public string Name;

        // Constructor
        public Person(string name) {
            Name = name;
        }
    }

    Person p = new Person("Ravi");

21. var vs dynamic
|-------------------------------------------------------------------------------------------------------|
|   Feature	     |                   var	                   |                 dynamic                |
|-------------------------------------------------------------------------------------------------------|
|   Type check	 |          Done at compile time	           |         Done at runtime                |
|-------------------------------------------------------------------------------------------------------|
|   Type fixed?	 |            Yes, once assigned	           |     No, can change at runtime          |
|-------------------------------------------------------------------------------------------------------|
|   Performance	 |       Faster (because it’s statically typed)|	Slower (because of runtime checks)  |
|-------------------------------------------------------------------------------------------------------|
|   Usage	     |       When type is obvious or complex	   |     When type is unknown until runtime |
|-------------------------------------------------------------------------------------------------------|

19. What is value type data and reference type data
    Value types: Store data directly. Stored in stack. (e.g., int, char, float, bool, struct)
    Reference types: Store reference (address) to data. Stored in heap. (e.g., class, string, array, object)

20. What is call by value and call by reference
    Call by value: Copies actual value. Changes don't affect the original.
    Call by reference: Passes reference. Changes affect the original variable.

42. Difference between var, dynamic, and object
    var: Implicitly typed variable at compile-time

    object: Base type of all types, requires explicit casting

    dynamic b = "Hello";    // Runtime type
    object c = 20;          // Needs casting
