1. Difference Between let and var:
- var is function-scoped; let is block-scoped.
- var allows redeclaration; let does not.
Example:
    var x = 5;
    var x = 10; // No error
    let y = 5;
    let y = 10; // Error: y has already been declared

2. Difference and similarities Between let and const:
- Both are block-scoped.
- let allows reassignment; const does not.
Example:
    let a = 10;
    a = 20; // OK
    const b = 30;
    b = 40; // Error: Assignment to constant variable

3. Why use 'use strict':
- Enables strict mode, which catches common coding mistakes.
Example:
    "use strict";
    x = 5; // Error: x is not defined

4. Use of typeof:
- Returns the type of a variable.
Example:
    typeof 42;           // "number"
    typeof "Hello";      // "string"
    typeof undefined;    // "undefined"

5. Which operator is overloaded:
- + is overloaded (addition and string concatenation).
Example:
    5 + 5 = 10
    "5" + 5 = "55"

6. Default value if variable is not assigned:
- undefined
Example:
    let a;
    console.log(a); // undefined

7. Calculation between number and undefined:
- Results in NaN (Not a Number)
Example:
    let a = 5 + undefined;
    console.log(a); // NaN

8. Default return value of a function:
- undefined, if no return is specified.
Example:
    function test() {}
    console.log(test()); // undefined

9. Explain window.document.write():
- Writes directly to the HTML document.
Example:
