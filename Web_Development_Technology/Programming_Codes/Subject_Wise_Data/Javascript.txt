
JavaScript
----------------
=======================================
           WHAT IS JAVASCRIPT?
=======================================

1. JavaScript is a lightweight, interpreted programming language used to create dynamic and interactive content on websites.

2. It runs in the web browser and is commonly used to:
   - Validate form inputs
   - Create interactive UI elements
   - Respond to user actions (like clicks or typing)
   - Communicate with servers (AJAX)
   - Manipulate HTML and CSS (DOM manipulation)

3. JavaScript is a **client-side scripting language**, but with environments like **Node.js**, it can also be used on the **server-side**.

4. JavaScript is **object-based**, **event-driven**, and **loosely typed**.

=======================================
        SIMPLE JAVASCRIPT EXAMPLE
=======================================

<script>
  function greet() {
    alert("Hello, welcome to JavaScript!");
  }
</script>

<button onclick="greet()">Click Me</button>

=======================================
       KEY FEATURES OF JAVASCRIPT
=======================================

1. **Lightweight and Interpreted**  
   - JavaScript is executed line-by-line in the browser without prior compilation.

2. **Dynamic Typing**  
   - Variables are not bound to a specific type and can hold any data type at runtime.

3. **Object-Based**  
   - JavaScript supports the use of objects for real-world modeling and structuring code.

4. **First-Class Functions**  
   - Functions are treated like variables. They can be assigned, passed, and returned.

5. **Event-Driven**  
   - JavaScript can respond to user actions (like clicks, keypresses, etc.) via events.

6. **Platform-Independent**  
   - Runs on any OS or browser with a JavaScript engine (cross-platform).

7. **Prototype-Based Inheritance**  
   - Uses prototypes instead of classical inheritance to extend objects.

8. **Asynchronous Programming**  
   - Supports non-blocking operations using callbacks, promises, and async/await.

9. **Client-Side Scripting**  
   - Runs in the browser, enhancing interactivity without reloading the page.

10. **Server-Side Capability**  
    - With environments like Node.js, JavaScript can also run on servers.

11. **DOM Manipulation**  
    - JavaScript can interact with and modify HTML/CSS using the DOM API.

12. **Highly Versatile**  
    - Can be used for frontend, backend, game development, mobile apps, etc.

Basic of Javascript 
------------------------

=======================================
          BASICS OF JAVASCRIPT
=======================================

1. What is JavaScript?
- JavaScript is a scripting language used to create dynamic and interactive content on websites.

2. How to Include JavaScript in HTML?
- Using the <script> tag
Example:
<script>
  alert("Hello, JavaScript!");
</script>

3. Variables
- Used to store data values.
- Declared using var, let, or const.
Example:
let name = "John";
const age = 25;

4. Data Types
- String, Number, Boolean, Object, Array, Null, Undefined
Example:
let city = "New York"; // String
let score = 90;        // Number

5. Operators
- +, -, *, /, %, ==, ===, !=, &&, ||, etc.
Example:
let result = 10 + 5;

6. Conditional Statements
- if, else if, else, switch
Example:
if (score > 50) {
  alert("Pass");
} else {
  alert("Fail");
}

7. Loops
- for, while, do...while
Example:
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

8. Functions
- Block of code that performs a task.
Example:
function greet() {
  alert("Welcome!");
}
greet();

9. Events
- Handle user interactions like click, hover.
Example:
<button onclick="greet()">Click Me</button>

10. Arrays
- Store multiple values in one variable.
Example:
let fruits = ["Apple", "Banana", "Cherry"];

11. Objects
- Collection of properties (key-value pairs).
Example:
let person = {
  name: "Alice",
  age: 30
};

12. DOM Manipulation
- Changing content and styles of HTML using JavaScript.
Example:
document.getElementById("demo").innerHTML = "Changed!";
