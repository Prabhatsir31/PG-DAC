HTML-5
---------
Key Features of HTML5:
   Doctype Simplified
   <!DOCTYPE html>
   New Semantic Elements
   Helps describe the meaning of content:
       <header>, <footer>, <article>, <section>, <nav>, <main>, etc.
   Multimedia Support (No Plugins Needed)
   Native tags for audio and video:
       <audio>, <video>
   Form Enhancements
   New input types and attributes:
       <input type="email">, <input type="date">, <input type="range">, required, placeholder, etc.
   Canvas and SVG
   For drawing graphics and animations:
       <canvas> tag for rendering graphics
       SVG (Scalable Vector Graphics) support
   Better APIs
   For dynamic content:
       Geolocation API
       Local Storage & Session Storage
       Drag-and-Drop API
Example HTML5 Page
   <!DOCTYPE html>
   <html>
     <head>
       <title>Page Title</title>
     </head>
     <body>
       <header>
         <!-- Logo, Site Title, Navigation -->
       </header>
       <nav>
         <!-- Main Navigation Links -->
       </nav>
       <main>
         <section>
           <article>
             <!-- Main Content -->
           </article>
         </section>
         <aside>
           <!-- Sidebar Content -->
         </aside>
       </main>
       <footer>
         <!-- Footer Information -->
       </footer>
     </body>
   </html>

Difference between HTML and HTML5 
----------------------------------------

Difference Between HTML and HTML5

1. Doctype Declaration:
   - HTML: The doctype declaration was <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN" "http://www.w3.org/TR/html4/strict.dtd"> in older versions (HTML4).
   - HTML5: The doctype declaration is simplified to <!DOCTYPE html>, making it cleaner and more straightforward.

2. Elements and Attributes:
   - HTML: HTML4 had several attributes that were often used to define specific document types, like <font>, <center>, and <b>.
   - HTML5: These elements and attributes were deprecated. HTML5 introduced new semantic elements such as <header>, <footer>, <article>, <section>, and <nav> to enhance readability and structure.

3. Multimedia Support:
   - HTML: No built-in support for audio or video elements. Developers had to rely on third-party plugins like Flash or QuickTime for embedding media.
   - HTML5: HTML5 introduced native support for audio and video through the <audio> and <video> elements, making it easier to embed multimedia content without external plugins.

4. Form Enhancements:
   - HTML: HTML4 had limited input types and form controls, such as <input type="text">, <input type="checkbox">, etc.
   - HTML5: HTML5 introduced new input types like email, date, number, url, range, search, and more, making form validation and user input easier. It also introduced the <datalist> and <progress> elements for better data handling and display.

5. New APIs and Features:
   - HTML: HTML lacked many advanced features for modern web applications.
   - HTML5: HTML5 introduced many new APIs and features to support richer web applications. Examples include:
     - Geolocation API: Allows websites to determine the user’s location.
     - Local Storage: A persistent client-side storage for web applications.
     - Canvas API: Allows drawing graphics and creating animations.
     - Web Workers: Allows background scripts to run without blocking the main UI thread.
     - WebSockets: Enables real-time communication between the client and server.

6. Deprecated Tags:
   - HTML: Older versions of HTML used tags like <font>, <center>, and <marquee>, which were commonly used for styling.
   - HTML5: These tags are deprecated in HTML5. Styling is now handled with CSS, and HTML5 focuses on semantic elements rather than presentation elements.

7. Character Encoding:
   - HTML: Older versions of HTML did not define a default character encoding, which led to potential issues with displaying special characters.
   - HTML5: It specifies UTF-8 encoding as the default and recommends adding <meta charset="UTF-8"> in the <head> for character encoding support.

8. Offline Support:
   - HTML: HTML did not provide native support for offline applications.
   - HTML5: HTML5 introduced the AppCache (Application Cache) API to allow websites to function offline by caching web assets.

9. Compatibility:
   - HTML: HTML4 was widely used for many years, and web browsers were built to render websites based on the HTML4 standard.
   - HTML5: HTML5 is backward compatible with previous versions of HTML, meaning older websites will continue to work in browsers that support HTML5. However, to fully leverage HTML5 features, modern browsers are recommended.

10. JavaScript Enhancements:
   - HTML: HTML4 had limited support for JavaScript interactions with the page.
   - HTML5: HTML5 introduced better support for JavaScript through new events and APIs, allowing for enhanced interactivity and manipulation of page elements.

Summary of Differences:

| Aspect           | HTML (HTML4)                                      | HTML5                                                          |
|------------------|---------------------------------------------------|----------------------------------------------------------------|
| Doctype          | <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN">| <!DOCTYPE html>                                                |
| Multimedia       | No native support, plugins required               | Native <audio> and <video> tags                                |
| Input Types      | Basic types like text, password, checkbox         | New types like date, email, number, range, etc.                |
| New Elements     | Limited semantic elements                         | New elements like <header>, <footer>, <article>, <section>, etc.|
| Form Enhancements| Limited form input capabilities                   | New input types, form validation, <datalist>, etc.             |
| Offline Support  | Not available                                     | AppCache API for offline functionality                         |
| Graphics         | No built-in graphics API                          | <canvas> for 2D graphics and animations                        |
| JavaScript       | Limited API support                               | New APIs for interaction (Geolocation, WebSockets, etc.)       |
| Compatibility    | Works in older browsers                           | Backward compatible with older HTML versions                   |

In short, HTML5 improves on HTML by making it more semantic, multimedia-friendly, and interactive, providing modern web applications with more robust capabilities.



CSS 
-------

What is CSS?

CSS stands for Cascading Style Sheets.

It is used to describe the look and formatting of a document written in HTML.

CSS allows you to apply styles such as:
- Colors
- Fonts
- Margins
- Padding
- Borders
- Positions
- Animations
- Layout (grid, flexbox, etc.)

CSS separates content from design, making HTML cleaner and more maintainable.

Example:
HTML (content):
<p>Hello World!</p>

CSS (style):
p {
  color: blue;
  font-size: 20px;
}

Types of CSS:
1. Inline CSS – Applied directly within an HTML tag.
   Example: <p style="color: red;">Hello</p>

2. Internal CSS – Written inside a <style> tag in the <head> section.
   Example:
   <style>
     p { color: green; }
   </style>

3. External CSS – Written in a separate .css file and linked to the HTML.
   Example: 
   <link rel="stylesheet" href="style.css">

Benefits of CSS:
- Saves time – Apply the same style across multiple pages.
- Better control – Precise control over design elements.
- Improved accessibility and performance.
- Easier maintenance – Update one file to change the entire look.

JavaScript
----------------
=======================================
           WHAT IS JAVASCRIPT?
=======================================

1. JavaScript is a lightweight, interpreted programming language used to create dynamic and interactive content on websites.

2. It runs in the web browser and is commonly used to:
   - Validate form inputs
   - Create interactive UI elements
   - Respond to user actions (like clicks or typing)
   - Communicate with servers (AJAX)
   - Manipulate HTML and CSS (DOM manipulation)

3. JavaScript is a **client-side scripting language**, but with environments like **Node.js**, it can also be used on the **server-side**.

4. JavaScript is **object-based**, **event-driven**, and **loosely typed**.

=======================================
        SIMPLE JAVASCRIPT EXAMPLE
=======================================

<script>
  function greet() {
    alert("Hello, welcome to JavaScript!");
  }
</script>

<button onclick="greet()">Click Me</button>

=======================================
       KEY FEATURES OF JAVASCRIPT
=======================================

1. **Lightweight and Interpreted**  
   - JavaScript is executed line-by-line in the browser without prior compilation.

2. **Dynamic Typing**  
   - Variables are not bound to a specific type and can hold any data type at runtime.

3. **Object-Based**  
   - JavaScript supports the use of objects for real-world modeling and structuring code.

4. **First-Class Functions**  
   - Functions are treated like variables. They can be assigned, passed, and returned.

5. **Event-Driven**  
   - JavaScript can respond to user actions (like clicks, keypresses, etc.) via events.

6. **Platform-Independent**  
   - Runs on any OS or browser with a JavaScript engine (cross-platform).

7. **Prototype-Based Inheritance**  
   - Uses prototypes instead of classical inheritance to extend objects.

8. **Asynchronous Programming**  
   - Supports non-blocking operations using callbacks, promises, and async/await.

9. **Client-Side Scripting**  
   - Runs in the browser, enhancing interactivity without reloading the page.

10. **Server-Side Capability**  
    - With environments like Node.js, JavaScript can also run on servers.

11. **DOM Manipulation**  
    - JavaScript can interact with and modify HTML/CSS using the DOM API.

12. **Highly Versatile**  
    - Can be used for frontend, backend, game development, mobile apps, etc.

Basic of Javascript 
------------------------

=======================================
          BASICS OF JAVASCRIPT
=======================================

1. What is JavaScript?
- JavaScript is a scripting language used to create dynamic and interactive content on websites.

2. How to Include JavaScript in HTML?
- Using the <script> tag
Example:
<script>
  alert("Hello, JavaScript!");
</script>

3. Variables
- Used to store data values.
- Declared using var, let, or const.
Example:
let name = "John";
const age = 25;

4. Data Types
- String, Number, Boolean, Object, Array, Null, Undefined
Example:
let city = "New York"; // String
let score = 90;        // Number

5. Operators
- +, -, *, /, %, ==, ===, !=, &&, ||, etc.
Example:
let result = 10 + 5;

6. Conditional Statements
- if, else if, else, switch
Example:
if (score > 50) {
  alert("Pass");
} else {
  alert("Fail");
}

7. Loops
- for, while, do...while
Example:
for (let i = 1; i <= 5; i++) {
  console.log(i);
}

8. Functions
- Block of code that performs a task.
Example:
function greet() {
  alert("Welcome!");
}
greet();

9. Events
- Handle user interactions like click, hover.
Example:
<button onclick="greet()">Click Me</button>

10. Arrays
- Store multiple values in one variable.
Example:
let fruits = ["Apple", "Banana", "Cherry"];

11. Objects
- Collection of properties (key-value pairs).
Example:
let person = {
  name: "Alice",
  age: 30
};

12. DOM Manipulation
- Changing content and styles of HTML using JavaScript.
Example:
document.getElementById("demo").innerHTML = "Changed!";
