Comments in C++ 
==============================

What are Comments?
---------------------
- Comments are non-executable statements in a program.
- They help developers explain and document code.
- The compiler ignores all comments.

Types of Comments in C++
----------------------------

1. Single-line Comment
   --------------------
   Syntax:
     // This is a single-line comment

   Example:
     int a = 5;  // Declare a variable a and assign 5

2. Multi-line Comment
   --------------------
   Syntax:
     /* 
        This is a 
        multi-line comment 
     */

   Example:
     /*
       The following code calculates
       the area of a rectangle
     */
     int area = length * width;

Why Use Comments?
---------------------
- To explain complex logic
- To improve code readability
- For documentation
- To temporarily disable (comment out) parts of code

Best Practices
-----------------
- Use comments to describe *why* something is done, not *what* is done.
- Keep comments updated.
- Avoid obvious comments.

Example Program with Comments
--------------------------------

#include <iostream>
using namespace std;

int main() {
    // Declare two numbers
    int num1 = 10;
    int num2 = 20;

    // Add the numbers and store in sum
    int sum = num1 + num2;

    /* Display the result
       using cout */
    cout << "Sum is: " << sum << endl;

    return 0;
}

Errors and Warnings in C++ Programming
==========================================

What are Errors?
-------------------
- Errors are issues in the program that prevent it from compiling or running.
- These must be fixed before the program executes properly.

Types of Errors
------------------

1. Syntax Errors
   - Occur when the code violates grammar rules of C++.
   - Detected at compile-time.
   - Example:
     int a = ;     // Error: missing value

2. Semantic Errors
   - Code compiles, but logic is incorrect.
   - No compiler error, but output is wrong.
   - Example:
     int a = 5, b = 0;
     int c = a / b;    // Division by zero (runtime issue)

3. Runtime Errors
   - Occur while the program is running.
   - Example:
     Accessing invalid memory, dividing by zero, null pointer dereference.

4. Logical Errors
   - Program runs, but gives incorrect output due to wrong logic.
   - Hardest to detect.
   - Example:
     int area = 2 * 3.14 * r;  // Incorrect formula for circle area

5. Linker Errors
   - Occur when object files fail to link correctly.
   - Example:
     Missing function definition during linking stage.

What are Warnings?
---------------------
- Warnings do not stop compilation but indicate potential issues.
- They highlight poor coding practices or potential bugs.

Common Warning Examples:
----------------------------
- Unused variables
  int x = 5;   // if x is never used

- Type conversion
  float f = 10 / 3;  // integer division, may warn about precision loss

- Comparison in assignment
  if (a = 5)   // assignment instead of comparison (should be a == 5)

How to Enable More Warnings (Good Practice)
----------------------------------------------
- Use compiler flags to enable extra warnings:
  g++ -Wall -Wextra myfile.cpp

Best Practices
------------------
- Fix all warnings, even if they don’t stop compilation.
- Keep compiler warnings enabled during development.
- Treat warnings as potential bugs.

Summary
-----------
| Type           | Detected At    | Stops Program  | Example                    |
|----------------|----------------|----------------|----------------------------|
| Syntax Error   | Compile-time   | Yes            | Missing semicolon          |
| Semantic Error | Compile-time   | Yes            | Using undeclared variable  |
| Runtime Error  | Runtime        | Yes (Crashes)  | Division by zero           |
| Logical Error  | Runtime        | No             | Wrong formula              |
| Linker Error   | Link time      | Yes            | Undefined reference        |
| Warning        | Compile-time   | No             | Unused variable            |


Statements and Functions in C++
=====================================

What is a Statement in C++?
------------------------------
- A statement is a complete instruction in a C++ program.
- It tells the computer to perform a specific action.
- Most statements end with a semicolon (;).

Types of Statements:
------------------------

1. Declaration Statement
   - Declares variables.
   - Example: int a;

2. Expression Statement
   - Performs computations or actions.
   - Example: a = 5 + 3;

3. Control Flow Statements
   - Change the execution path.
   - if, if-else, switch, loops (for, while, do-while)

4. Compound Statement
   - A group of statements enclosed in `{}`.
   - Treated as a single unit (block).
   - Example:
     {
       int x = 5;
       cout << x;
     }

5. Jump Statements
   - Change the control unconditionally.
   - break, continue, return, goto

What are Functions in C++?
------------------------------------------
- A function is a block of code designed to perform a specific task.
- Used to organize code, improve readability, and enable reusability.

Syntax of a Function:
-------------------------
return_type function_name(parameter_list) {
    // body of the function
    return value;
}

Example:
------------
int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(5, 3);
    cout << "Sum is: " << result;
    return 0;
}

Types of Functions:
-----------------------

1. Built-in Functions
   - Provided by C++ standard libraries.
   - Example: `sqrt()`, `pow()`, `cin`, `cout`

2. User-defined Functions
   - Created by programmers.

Function Components:
------------------------

1. Function Declaration / Prototype
   - Declares the function before usage.
   - Example: int add(int, int);

2. Function Definition
   - Contains actual body/code of the function.

3. Function Call
   - Invokes the function.
   - Example: add(2, 3);

Parameter Types:
--------------------
- Formal Parameters – In function definition.
- Actual Parameters – In function call.

Return Statement:
---------------------
- Sends the result back to the calling function.
- Example: return x + y;

Advantages of Functions:
----------------------------
- Code Reusability
- Modular approach
- Easy to debug and test


Data Input and Output in C++
=====================================

What is Input and Output (I/O)?
----------------------------------
- Input: Data received by the program from the user.
- Output: Data displayed by the program to the user.

I/O in C++ is handled using:
--------------------------------
1. cin → for input
2. cout → for output
3. Defined in the `<iostream>` header


Output Using cout (Console Output)
=====================================
- Used to display output on the screen.
- Syntax:
    cout << value;

- Example:
    int a = 10;
    cout << "Value of a is: " << a;

- You can chain multiple outputs:
    cout << "Sum = " << a + b << endl;

- `endl` → Ends the current line and flushes the output buffer.


Input Using cin (Console Input)
=====================================
- Used to take input from the user.
- Syntax:
    cin >> variable;

- Example:
    int num;
    cout << "Enter a number: ";
    cin >> num;

- Multiple inputs:
    int a, b;
    cin >> a >> b;


Example Program (cin and cout):
--------------------------------------

#include <iostream>
using namespace std;

int main() {
    int age;
    string name;

    cout << "Enter your name: ";
    cin >> name;

    cout << "Enter your age: ";
    cin >> age;

    cout << "Hello " << name << ", you are " << age << " years old.";
    return 0;
}


Common Issues with cin
----------------------------
- When using `cin >>` with strings, it only reads one word (stops at space).
- To read full line:
    - Use `getline(cin, variable);`

Example:
    string name;
    getline(cin, name);

C++ Program Execution Model
=====================================

What is a Program Execution Model?
-------------------------------------
- The process by which a C++ program is translated from source code to machine-executable code and then executed.
- It involves multiple steps:
  1. Writing source code
  2. Compiling
  3. Linking
  4. Loading
  5. Execution


Steps of C++ Program Execution:
=====================================

1. Editing (Writing Source Code)
   ----------------------------------
   - You write the code using a text editor or IDE.
   - File extension is `.cpp`.
   - Example:
       int main() {
           cout << "Hello";
           return 0;
       }

2. Preprocessing
   ------------------
   - Handles preprocessor directives like `#include`, `#define`.
   - Produces expanded source code.
   - Example: `#include <iostream>` is replaced by actual content of that file.

3. Compilation
   ----------------
   - Converts the expanded source code into object code (.obj or .o).
   - Syntax errors are checked here.
   - Output: machine-level code without resolving external references.

4. Linking
   ------------
   - Combines object code with libraries (like iostream, math, etc.).
   - Resolves function calls like `cout`, `cin`, `main`, etc.
   - Output: Executable file (.exe)

5. Loading
   ------------
   - The executable is loaded into memory by the OS.
   - Memory is allocated for code, variables, stack, and heap.

6. Execution
   --------------
   - CPU begins executing the code starting from `main()`.
   - The program performs tasks as coded.


Summary Table
===============

| Stage         | Tool Used        | Output             | Description                        |
|---------------|------------------|--------------------|------------------------------------|
| Editing       | Text editor/IDE  | .cpp file          | Write source code                  |
| Preprocessing | C++ Preprocessor | Expanded code      | Handles macros, includes           |
| Compilation   | Compiler         | .obj / .o file     | Translates to machine code         |
| Linking       | Linker           | .exe file          | Resolves external references       |
| Loading       | Loader (OS)      | Loaded to memory   | Prepares program for execution     |
| Execution     | CPU              | Output on screen   | Runs the program                   |


Example Toolchain:
-------------------------------------------
- Editor: VS Code / Code::Blocks / Turbo C++
- Compiler: g++, clang++
- Linker: GNU Linker (ld)
- OS Loader: Part of Operating System


C++ Core Language vs Standard Library vs STL
===============================================

1. C++ Core Language
------------------------
- The core language includes the essential syntax, grammar, and low-level features needed to write basic C++ programs.
- It defines how to declare variables, use loops, functions, classes, inheritance, etc.

Features:
  - Variables and Data Types (int, float, char)
  - Control Structures (if, switch, for, while)
  - Functions (user-defined)
  - Classes & Objects
  - Inheritance, Polymorphism
  - Templates (function/class templates)
  - Pointers and References
  - Operator Overloading

Example:

int main() {
    int a = 5;
    if (a > 0) {
        cout << "Positive";
    }
}

2. C++ Standard Library
--------------------------
- A collection of pre-written functions and classes provided with the language.
- It extends the core language by offering common utilities.

Main Components:
  - Input/Output: `cin`, `cout`, `cerr`, `clog` (from `<iostream>`)
  - String operations: `std::string` (from `<string>`)
  - Math functions: `sqrt()`, `pow()` (from `<cmath>`)
  - Time: `time()`, `clock()` (from `<ctime>`)
  - File handling: `ifstream`, `ofstream` (from `<fstream>`)

Example:
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    cout << "Square root of 16 is " << sqrt(16);
}

3. Standard Template Library (STL)
-------------------------------------
- A powerful set of generic classes and functions built using C++ templates.
- Designed for efficient data storage and manipulation.
- Part of the Standard Library but often referred to as STL due to its large scope.

Components of STL:

A. Containers – Store data
   - `vector`, `list`, `deque`, `set`, `map`, `stack`, `queue`

B. Algorithms – Work on containers
   - `sort()`, `find()`, `count()`, `binary_search()`

C. Iterators – Used to access container elements
   - `begin()`, `end()`, `advance()`, `next()`

Example:
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {5, 3, 9, 1};
    sort(v.begin(), v.end());

    for (int x : v)
        cout << x << " ";
}



Summary: Differences at a Glance
=====================================

| Feature             | C++ Core Language             | Standard Library                       | STL                                  |
|---------------------|-------------------------------|----------------------------------------|---------------------------------------|
| Purpose             | Basic building blocks         | General-purpose utilities              | Data structures & algorithms          |
| Scope               | Syntax, classes, loops, etc.  | I/O, strings, math, time               | Vectors, maps, sort, iterators        |
| Template-based?     | Partially (function templates)| No                                     | Yes (heavily uses templates)          |
| Real-world Use Case | Defining behavior             | Reading input or computing powers      | Sorting a list, storing a dictionary  |



Variables and Data Types
============================

What is a Variable?
---------------------
- A variable is a named memory location used to store data.
- Its value can change during program execution.

Declaration Syntax:
  data_type variable_name;

Example:
  int age;
  float salary;

Variable Initialization:
  int age = 25;
  char grade = 'A';

Rules for Naming Variables:
- Must begin with a letter or underscore (_)
- Can contain letters, digits, and underscores
- Cannot use C++ reserved keywords (like int, return)
- Case sensitive (age and Age are different)

Types of Variables:
---------------------
1. Local Variable
   - Declared inside a function or block
   - Accessible only within that block

2. Global Variable
   - Declared outside all functions
   - Accessible throughout the program

3. Static Variable
   - Retains its value between function calls
   - Declared with `static` keyword

4. Constant Variable
   - Value cannot be changed after initialization
   - Declared with `const` keyword

Example:
  const float PI = 3.14;

C++ Data Operations & Key Operator Concepts
================================================

1. Introduction to Data Operations
----------------------------------
- Data operations include arithmetic, assignment, comparison, and logical operations.
- They allow processing and manipulation of variables and values in C++ programs.

Example:
int a = 10, b = 5;
int result = a + b;  // result is 15


2. Basic Operations
-----------------------------------------------------------
Operator | Meaning            | Example        | Result
---------|--------------------|----------------|--------
+        | Addition           | 10 + 5         | 15
-        | Subtraction        | 10 - 5         | 5
*        | Multiplication     | 10 * 5         | 50
/        | Division           | 10 / 5         | 2
%        | Modulus (remainder)| 10 % 3        | 1

Code:
int a = 10, b = 3;
cout << "a + b = " << a + b << endl;


3. Precedence and Associativity
-------------------------------------
- Determines the **order** of operation execution in complex expressions.
- Associativity defines **left-to-right** or **right-to-left** evaluation.

Example:
int x = 2 + 3 * 4;   // x = 2 + 12 = 14 (because * has higher precedence)

Operator Precedence (High to Low):
1. ()            → Parentheses
2. ++, --        → Unary operators
3. *, /, %       → Multiplicative
4. +, -          → Additive
5. <, >, <=, >=  → Relational
6. ==, !=        → Equality
7. &&            → Logical AND
8. ||            → Logical OR
9. =, +=, -=     → Assignment (Right to Left)


4. Prefix/Postfix ++ and --
-----------------------------------
Prefix: ++a → Increment first, then use  
Postfix: a++ → Use first, then increment

Code:
int a = 5;
cout << ++a << endl; // 6
cout << a++ << endl; // 6 (a becomes 7 after this line)
cout << a << endl;   // 7


5. Compound Assignment Operators
-------------------------------------
Shorthand for arithmetic + assignment.

Operator | Meaning         | Equivalent To
---------|-----------------|----------------
+=       | a = a + b       | a += b
-=       | a = a - b       | a -= b
*=       | a = a * b       | a *= b
/=       | a = a / b       | a /= b
%=       | a = a % b       | a %= b

Code:
int x = 10;
x += 5;  // x is now 15


6. Relational Operators
--------------------------
Used to compare values (result is true/false)

Operator | Meaning
---------|------------------
==       | Equal to
!=       | Not equal to
>        | Greater than
<        | Less than
>=       | Greater or equal
<=       | Less or equal

Code:
int a = 10, b = 20;
cout << (a > b);  // Output: 0 (false)


7. Logical Operators
-----------------------
Used for combining conditions.

Operator | Meaning        | Example
---------|----------------|----------------------
&&       | Logical AND    | a > 10 && b < 20
||       | Logical OR     | a == 10 || b == 5
!        | Logical NOT    | !(a == 10)

Code:
int a = 5;
if (a > 0 && a < 10)
    cout << "Single-digit positive number";

Flow Control in C++ Programming
===================================

1. Introduction to Flow Control
--------------------------------
- Flow control structures determine the order in which statements are executed.
- C++ supports decision-making using:
  - if statements
  - if-else if ladder
  - switch-case
  - ternary (conditional) operator


2. If Statement
---------------------
- Used to execute a block of code only if a condition is true.

Syntax:
if (condition) {
    // code to execute
}

Example:
int age = 20;
if (age >= 18) {
    cout << "You are eligible to vote.";
}


3. If-Else Statement
----------------------
- Adds an alternative block if the condition is false.

Syntax:
if (condition) {
    // true block
} else {
    // false block
}

Example:
int num = 7;
if (num % 2 == 0) {
    cout << "Even number";
} else {
    cout << "Odd number";
}


4. Else If Ladder
---------------------
- Used to check multiple conditions sequentially.

Syntax:
if (condition1) {
    // code
} else if (condition2) {
    // code
} else {
    // default code
}

Example:
int marks = 85;
if (marks >= 90) {
    cout << "Grade A";
} else if (marks >= 75) {
    cout << "Grade B";
} else {
    cout << "Grade C";
}


5. Switch Statement
-----------------------
- Used when you want to choose between multiple values of a single variable.

Syntax:
switch (expression) {
    case value1:
        // code
        break;
    case value2:
        // code
        break;
    default:
        // default code
}

Example:
int day = 3;
switch (day) {
    case 1: cout << "Monday"; break;
    case 2: cout << "Tuesday"; break;
    case 3: cout << "Wednesday"; break;
    default: cout << "Invalid day";
}


6. Ternary Operator
---------------------
- A compact version of if-else for simple conditions.

Syntax:
(condition) ? value_if_true : value_if_false;

Example:
int a = 10, b = 20;
int max = (a > b) ? a : b;
cout << "Max is: " << max;


Sample Program Demonstrating All:
--------------------------------------
#include <iostream>
using namespace std;

int main() {
    int number;
    cout << "Enter a number: ";
    cin >> number;

    // If-Else
    if (number > 0) {
        cout << "Positive";
    } else if (number < 0) {
        cout << "Negative";
    } else {
        cout << "Zero";
    }

    // Switch
    switch (number) {
        case 1: cout << " - One"; break;
        case 2: cout << " - Two"; break;
        default: cout << " - Not 1 or 2";
    }

    // Ternary
    string result = (number % 2 == 0) ? "Even" : "Odd";
    cout << " and it is " << result << endl;

    return 0;
}


Loops in C++ Programming
=============================

What is a Loop?
--------------------
- A loop is a control structure that allows repeating a block of code multiple times.
- Loops are used when you want to perform repetitive tasks efficiently.

Types of Loops in C++:
1. for loop
2. while loop
3. do-while loop
4. Nested loops
5. Range-based for loop (since C++11)


1. for Loop
-----------------
- Used when the number of iterations is known.

Syntax:
for (initialization; condition; update) {
    // loop body
}

Example:
for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
// Output: 1 2 3 4 5


2. while Loop
------------------
- Used when the number of iterations is not known in advance.
- Condition is checked before each iteration.

Syntax:
while (condition) {
    // loop body
}

Example:
int i = 1;
while (i <= 5) {
    cout << i << " ";
    i++;
}
// Output: 1 2 3 4 5


3. do-while Loop
---------------------
- Similar to while, but condition is checked **after** executing the loop body.
- Loop body executes at least once.

Syntax:
do {
    // loop body
} while (condition);

Example:
int i = 1;
do {
    cout << i << " ";
    i++;
} while (i <= 5);
// Output: 1 2 3 4 5


4. Nested Loops
--------------------
- A loop inside another loop.

Example:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 2; j++) {
        cout << "(" << i << "," << j << ") ";
    }
}
// Output: (1,1) (1,2) (2,1) (2,2) (3,1) (3,2)


5. Range-Based for Loop (C++11)
--------------------------------------
- Used to iterate over arrays, vectors, and other containers.

Syntax:
for (datatype variable : container) {
    // code
}

Example:
int arr[] = {10, 20, 30};
for (int x : arr) {
    cout << x << " ";
}
// Output: 10 20 30


Control Statements with Loops
----------------------------------

1. break:
   - Exits the loop immediately.

   Example:
   for (int i = 1; i <= 10; i++) {
       if (i == 5) break;
       cout << i << " ";
   }
   // Output: 1 2 3 4

2. continue:
   - Skips current iteration and continues with the next.

   Example:
   for (int i = 1; i <= 5; i++) {
       if (i == 3) continue;
       cout << i << " ";
   }
   // Output: 1 2 4 5


Summary Table
------------------
| Loop Type      | Condition Check  | Use Case                   |
|----------------|------------------|----------------------------|
| for            | Before loop      | Known number of iterations |
| while          | Before loop      | Unknown iterations         |
| do-while       | After loop       | At least one execution     |
| range-based    | Automatic        | Containers, arrays         |


Complete Example
----------------------
#include <iostream>
using namespace std;

int main() {
    // for loop
    for (int i = 1; i <= 3; i++) {
        cout << "For: " << i << endl;
    }

    // while loop
    int j = 1;
    while (j <= 3) {
        cout << "While: " << j << endl;
        j++;
    }

    // do-while loop
    int k = 1;
    do {
        cout << "Do-While: " << k << endl;
        k++;
    } while (k <= 3);

    return 0;
}


Arrays in C++
===================

What is an Array?
------------------
- An array is a collection of elements of the **same data type** stored in **contiguous memory locations**.
- It allows accessing and manipulating multiple values using a single name and an index.

Syntax:
    data_type array_name[size];

Example:
    int numbers[5] = {1, 2, 3, 4, 5};


Types of Arrays in C++
============================

1. One-Dimensional Array (1D Array)
------------------------------------
- Stores data in a single row (like a list).

Declaration:
    int arr[5] = {10, 20, 30, 40, 50};

Access:
    cout << arr[2];   // Output: 30

Loop Example:
    for (int i = 0; i < 5; i++) {
        cout << arr[i] << " ";
    }


2. Two-Dimensional Array (2D Array)
------------------------------------
- Stores data in rows and columns (like a matrix).

Declaration:
    int matrix[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

Access:
    cout << matrix[1][2];   // Output: 6

Nested Loop Example:
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            cout << matrix[i][j] << " ";
        }
        cout << endl;
    }

3. Multidimensional Array (3D and beyond)
------------------------------------------
- Arrays with more than two dimensions.
- Used in advanced applications like 3D games, simulations, etc.

Declaration:
    int cube[2][2][2] = {
        { {1, 2}, {3, 4} },
        { {5, 6}, {7, 8} }
    };

Access:
    cout << cube[1][0][1];  // Output: 6

4. Character Array (C-Style String)
------------------------------------
- Array of characters ending with null character `'\0'`.

Declaration:
    char name[6] = {'A', 'l', 'i', 'c', 'e', '\0'};
    OR
    char city[] = "Delhi";

Access:
    cout << name;   // Output: Alice

Using `cin.getline` for full input:
    char line[100];
    cin.getline(line, 100);


5. Array of Strings
------------------------------------
- Array of character arrays OR use `string` array (C++ STL).

Using character array:
    char cities[3][10] = { "Delhi", "Mumbai", "Pune" };

Using string type:
    string cities[3] = { "Delhi", "Mumbai", "Pune" };

Loop Example:
    for (int i = 0; i < 3; i++) {
        cout << cities[i] << endl;
    }


Common Mistakes to Avoid
----------------------------------------------------
- Accessing out-of-bound index → causes undefined behavior
- Forgetting the `\0` at the end of character arrays
- Using uninitialized arrays

Summary
----------------------------------------------------
| Type                | Structure              | Use Case                        |
|---------------------|------------------------|---------------------------------|
| 1D Array            | Linear                 | Lists, Marks, Scores            |
| 2D Array            | Matrix (rows, cols)    | Tables, Grid-based games        |
| Multidimensional    | 3D and above           | Complex data like 3D objects    |
| Character Array     | String-like            | Storing words                   |
| Array of Strings    | Collection of strings  | Cities, Names, etc              |

Complete Example
-------------------------
#include <iostream>
#include <string>
using namespace std;

int main() {
    // 1D Array
    int scores[3] = {90, 80, 85};
    cout << "1D Array: ";
    for (int i = 0; i < 3; i++) {
        cout << scores[i] << " ";
    }
    cout << endl;

    // 2D Array
    int table[2][2] = { {1, 2}, {3, 4} };
    cout << "2D Array:\n";
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            cout << table[i][j] << " ";
        }
        cout << endl;
    }

    // Character Array
    char name[] = "Alice";
    cout << "Character Array: " << name << endl;

    // Array of Strings
    string cities[2] = {"Delhi", "Pune"};
    cout << "Array of Strings:\n";
    for (int i = 0; i < 2; i++) {
        cout << cities[i] << endl;
    }

    return 0;
}

Pointers in C++ Programming
=========================================

1. Introduction to Pointers
-----------------------------
- A pointer is a variable that stores the memory address of another variable.
- It allows for dynamic memory management, efficient array handling, and more.

Example:
int x = 10;
int* ptr = &x;

2. Declaring and Using Pointers
-------------------------------
Syntax:
    data_type* pointer_name;

Example:
    int num = 5;
    int* p = &num;

Dereferencing:
    cout << *p;  // outputs the value at the address p points to

3. Pointer to char
-------------------
- Commonly used to handle strings or character arrays.

Example:
    char ch = 'A';
    char* p = &ch;
    cout << *p;  // Output: A

Character arrays:
    char* name = "Hello";
    cout << name;  // Output: Hello

4. Program Memory Map Revisited
-------------------------------
Typical memory layout:
- Code Segment: stores compiled code
- Stack: stores function calls, local variables
- Heap: stores dynamically allocated memory
- Data Segment: stores global/static variables

5. Dynamic Memory Allocation
-----------------------------
- Uses `new` and `delete` to allocate/free memory at runtime.

Syntax:
    int* p = new int;        // single int
    *p = 25;

    delete p;                // free memory

    int* arr = new int[5];   // array of 5 integers
    delete[] arr;            // free array memory

6. Dangling Pointers
---------------------
- A pointer pointing to memory that has been deleted or out of scope.

Example:
    int* ptr = new int(5);
    delete ptr;
    cout << *ptr;  // Undefined behavior (dangling)

7. When new Fails
------------------
- If allocation fails, `new` throws `std::bad_alloc`.

Handling with try-catch:
try {
    int* p = new int[1000000000];
} catch (bad_alloc &e) {
    cout << "Allocation failed: " << e.what();
}

8. Null Pointer Safety
-----------------------
- Always initialize pointers to `nullptr`.

Example:
    int* p = nullptr;

- Before dereferencing:
    if (p != nullptr)
        cout << *p;

9. Memory Leaks
----------------
- Occur when dynamically allocated memory is not freed.
- Leads to wasted memory and potential crashes.

Bad:
    int* p = new int(10);
    p = new int(20);  // previous memory leaked

Solution:
    delete p; before reassigning

10. Dynamically Allocated Arrays
---------------------------------
- Useful when size is unknown at compile time.

Example:
    int n;
    cin >> n;
    int* arr = new int[n];

    for (int i = 0; i < n; i++)
        cin >> arr[i];

    delete[] arr;


Summary
----------------
-----------------------------------------------------------
| Concept                  | Description                     |
|--------------------------|---------------------------------|
| Pointer                  | Stores memory address           |
| Dereferencing            | Access value using *ptr         |
| new/delete               | Allocate and deallocate memory  |
| nullptr                  | Safe null initialization        |
| Dangling pointer         | Pointer to deleted memory       |
| Memory leak              | Allocated memory not released   |
| Dynamic arrays           | Arrays created with new[]       |

Strings in C++
======================

1. Introduction to Strings
---------------------------
- A string is a sequence of characters used to store and manipulate text.
- In C++, strings can be handled using:
  1. C-style strings (character arrays)
  2. std::string class (C++ Standard Library)

2. Character Manipulation
---------------------------
- Characters are stored using the `char` data type.
- Single characters can be accessed and manipulated using indices.

Example:
    char letter = 'A';
    letter += 1;  // becomes 'B'

3. C-String Manipulation (Character Arrays)
--------------------------------------------
- A C-string is a null-terminated array of characters.

Declaration:
    char name[6] = {'H', 'e', 'l', 'l', 'o', ' '};
    OR
    char name[] = "Hello";

Accessing:
    cout << name[1];  // Output: e

Reading Input:
    char str[50];
    cin >> str;  // reads until space

Using getline:
    cin.getline(str, 50);  // reads full line


4. C-String Concatenation and Copy
-----------------------------------

C++ provides functions in `<cstring>` header:
- `strcpy(dest, src)` – copy string
- `strcat(dest, src)` – concatenate
- `strlen(str)` – length of string
- `strcmp(str1, str2)` – compare strings

Example:
    char str1[20] = "Hello";
    char str2[] = "World";
    strcat(str1, str2);   // str1 becomes "HelloWorld"


5. Introducing std::string
----------------------------
- A modern and flexible way to use strings in C++.
- Part of the Standard Library (`#include <string>`)

Benefits:
- Automatically manages memory
- Supports many operations like `+`, `==`, `.length()`


6. Declaring and Using std::string
-----------------------------------

Declaration:
    string name = "John";

Operations:
    name += " Doe";           // Concatenation
    int len = name.length();  // Length
    cout << name[0];          // Access character

Input:
    string city;
    getline(cin, city);       // Reads full line including spaces

Comparison:
    string a = "hello", b = "world";
    if (a == b) {
        cout << "Same";
    } else {
        cout << "Different";
    }


7. Common std::string Methods
-------------------------------

| Method             | Description                              |
|--------------------|------------------------------------------|
| length() / size()  | Returns the number of characters         |
| at(index)          | Returns character at given index         |
| front()            | Returns first character                  |
| back()             | Returns last character                   |
| append(str)        | Appends given string                     |
| insert(pos, str)   | Inserts string at specified position     |
| erase(pos, len)    | Erases portion from the string           |
| substr(pos, len)   | Returns substring                        |
| find(str)          | Finds first occurrence                   |
| rfind(str)         | Finds last occurrence                    |
| replace(pos, len, str) | Replaces portion with new string     |
| empty()            | Checks if string is empty                |
| clear()            | Clears the content                       |
| compare(str)       | Compares strings lexicographically       |
| c_str()            | Converts to C-style string               |

Example:
    string s = "programming";
    s.insert(0, "C++ ");
    s.replace(4, 3, "LANG");
    string sub = s.substr(0, 5);


Summary Table
--------------------------------------------------------------
| Type           | Header       | Features                    |
|----------------|--------------|-----------------------------|
| C-style string | <cstring>    | Manual memory, char arrays  |
| std::string    | <string>     | Dynamic, safer and easier   |

Lambda Functions in C++
==============================

1. Introduction to Lambda Functions
-----------------------------------
- A lambda function is an anonymous function defined using a concise syntax.
- It can be defined inside functions and passed as an argument to algorithms or functions.

Basic Syntax:
    [capture_list](parameter_list) -> return_type {
        // function body
    };

The `-> return_type` is optional and inferred in most cases.

Example:
    auto add = [](int a, int b) {
        return a + b;
    };
    cout << add(3, 4);  // Output: 7


2. Declaring and Using Lambda Functions
---------------------------------------

- You can store lambda in a variable using `auto`:
    auto greet = []() {
        cout << "Hello, World!";
    };
    greet();  // Calls the lambda

- Lambda with parameters:
    auto multiply = [](int x, int y) {
        return x * y;
    };

- Lambda with return type:
    auto divide = [](int a, int b) -> double {
        return (double)a / b;
    };


3. Capture Lists
-----------------
- The capture list is used to capture external variables in the lambda function.

Types of capture:

a. Capture by value:
    int x = 10;
    auto show = [x]() {
        cout << x;
    };

b. Capture by reference:
    int x = 10;
    auto modify = [&x]() {
        x += 5;
    };


4. Capture All in Context
--------------------------

a. Capture all by value:
    auto func = [=]() {
        // captures all outer variables by value
    };

b. Capture all by reference:
    auto func = [&]() {
        // captures all outer variables by reference
    };

c. Mixed capture:
    auto func = [=, &y]() {
        // all by value except y by reference
    };


5. Example Program
-------------------
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 10;

    auto sum = [=]() {
        return a + b;
    };

    auto increment = [&]() {
        a++;
        b++;
    };

    cout << "Sum: " << sum() << endl;
    increment();
    cout << "After increment - a: " << a << ", b: " << b << endl;

    return 0;
}

Output:
Sum: 15
After increment - a: 6, b: 11


Summary
-----------------------------------------------------------------
| Feature              | Description                             |
|----------------------|-----------------------------------------|
| []                   | Capture list                            |
| ()                   | Parameters                              |
| -> return_type       | Optional return type                    |
| [=]                  | Capture all by value                    |
| [&]                  | Capture all by reference                |
| [x, &y]              | x by value, y by reference              |


Function Templates in C++
===========================

1. Introduction to Function Templates
-------------------------------------
- A function template allows you to write a single function to work with different data types.
- It avoids code duplication by using placeholders for data types.
- Defined using the `template` keyword.

Syntax:
    template <typename T>
    return_type function_name(T arg) {
        // function body
    }

Note: You can use `class` instead of `typename`. Both are equivalent.


2. Trying Out Function Templates
---------------------------------

Example: Generic swap function
    template <typename T>
    void mySwap(T& a, T& b) {
        T temp = a;
        a = b;
        b = temp;
    }

    int main() {
        int x = 5, y = 10;
        mySwap(x, y);  // Works with int

        double a = 1.1, b = 2.2;
        mySwap(a, b);  // Works with double
    }


3. Template Type Deduction and Explicit Arguments
--------------------------------------------------

- The compiler can automatically deduce the type from the arguments.

Example:
    template <typename T>
    void print(T value) {
        cout << value << endl;
    }

    print(5);          // T is int
    print("hello");    // T is const char*

- You can also provide the type explicitly:
    print<int>(100);


4. Template Parameters by Reference
-----------------------------------

- Templates can accept arguments by reference to avoid copying.

Example:
    template <typename T>
    void increment(T& val) {
        val++;
    }

    int main() {
        int a = 10;
        increment(a);   // a becomes 11
    }


5. Template Specialization
---------------------------

- Allows you to define a custom version of a template for a specific data type.

Syntax:
    template <>
    void print<string>(string value) {
        cout << "String: " << value << endl;
    }

    int main() {
        print(10);             // Generic version
        print<string>("Hi");   // Specialized version
    }


Summary
-----------------------------------------------------------
| Feature                 | Purpose                             |
|-------------------------|-------------------------------------|
| Function Template       | Generic function for multiple types |
| Type Deduction          | Infers type from arguments          |
| Explicit Type           | Manually specify type               |
| Reference Parameters    | Avoids copying, modifies original   |
| Template Specialization | Custom logic for specific types     |


C++ Classes and Objects
============================

1. Intro to Classes
-------------------
- A class is a blueprint for creating objects.
- It can contain data members (variables) and member functions (methods).

Syntax:
    class ClassName {
    public:
        // data members
        // member functions
    };

Example:
    class Person {
    public:
        string name;
        int age;
        void display() {
            cout << name << " is " << age << " years old.";
        }
    };

2. Your First Class
-------------------
Example:
    class Rectangle {
    public:
        int length, width;

        int area() {
            return length * width;
        }
    };

    int main() {
        Rectangle r;
        r.length = 5;
        r.width = 4;
        cout << r.area();  // Output: 20
    }

3. C++ Constructors
-------------------
- A constructor is a special function automatically called when an object is created.
- It has the same name as the class and no return type.

Example:
    class Student {
    public:
        Student() {
            cout << "Constructor called";
        }
    };

4. Defaulted Constructors
-------------------------
- Compiler provides a default constructor if none is defined.
- Can explicitly default one:
    Student() = default;

5. Setters and Getters
----------------------
- Used to encapsulate data and control access.

Example:
    class Employee {
    private:
        int salary;
    public:
        void setSalary(int s) {
            salary = s;
        }
        int getSalary() {
            return salary;
        }
    };

6. Class Across Multiple Files
------------------------------
- Class declarations go in header (.h) files.
- Definitions go in .cpp files.

Example:
    // Employee.h
    class Employee {
    public:
        void work();
    };

    // Employee.cpp
    void Employee::work() {
        cout << "Working...";
    }

7. Arrow Pointer Call Notation
------------------------------
- Used when accessing members via pointers.

Example:
    Employee* e = new Employee();
    e->work();  // Equivalent to (*e).work()

8. Destructors
--------------
- Special function called when object goes out of scope or is deleted.
- Used to free resources.
- Begins with ~ and has no arguments.

Example:
    class Sample {
    public:
        ~Sample() {
            cout << "Destructor called";
        }
    };

9. Order of Constructor and Destructor Calls
--------------------------------------------
- Constructors are called top-down in inheritance.
- Destructors are called bottom-up (reverse order).

10. The this Pointer
--------------------
- Refers to the current object.
- Useful when parameter names shadow member variables.

Example:
    class Box {
    private:
        int length;
    public:
        void setLength(int length) {
            this->length = length;
        }
    };

11. struct
----------
- Similar to class, but default access is public.
- Can have functions and constructors in C++.

Example:
    struct Point {
        int x, y;
        void show() {
            cout << x << "," << y;
        }
    };

12. Size of Objects
-------------------
- The size of an object depends on its data members.
- Member functions do not contribute to object size.
- Padding may affect size for alignment.

Example:
    class Test {
        int a;
        char b;
    };
    sizeof(Test);  // May be 8 bytes due to padding


Summary
-----------------------------------------------------------
| Feature              | Description                         |
|----------------------|-------------------------------------|
| class                | Blueprint for objects               |
| constructor          | Initializes object                  |
| destructor           | Cleans up object                    |
| this                 | Refers to current object            |
| struct               | Like class but public by default    |
| ->                   | Access members via pointer          |


Inheritance in C++ (Complete Notes)
=======================================
1. Introduction to Inheritance
------------------------------
- Inheritance is a feature of object-oriented programming that allows one class (derived) to inherit properties and behaviors from another class (base).
- Promotes code reuse and establishes relationships between classes.

Syntax:
    class Derived : access_specifier Base {
        // members of Derived
    };


2. Types of Inheritance in C++
------------------------------

1. Single Inheritance
---------------------
- One base class and one derived class.

    class Animal {
    public:
        void eat() {}
    };

    class Dog : public Animal {
    public:
        void bark() {}
    };

2. Multilevel Inheritance
-------------------------
- A derived class becomes base for another class.

    class Animal {
    public:
        void eat() {}
    };

    class Dog : public Animal {
    public:
        void bark() {}
    };

    class Puppy : public Dog {
    public:
        void weep() {}
    };

3. Multiple Inheritance
-----------------------
- A class inherits from more than one base class.

    class A {
    public:
        void msgA() {}
    };

    class B {
    public:
        void msgB() {}
    };

    class C : public A, public B {
    public:
        void msgC() {}
    };

4. Hierarchical Inheritance
---------------------------
- Multiple classes inherit from a single base class.

    class Animal {
    public:
        void eat() {}
    };

    class Dog : public Animal {
    public:
        void bark() {}
    };

    class Cat : public Animal {
    public:
        void meow() {}
    };

5. Hybrid Inheritance
---------------------
- Combination of more than one type of inheritance.

    Example: Combination of multiple and hierarchical.
    Handled carefully to avoid ambiguity using virtual inheritance.
    #include <iostream>
    using namespace std;

    // Base class
    class A {
        // members of A
    };

    // First level derived class
    class B : public A {
        // members of B
    };

    // Another first level derived class
    class C : public A {
        // members of C
    };

    // Second level derived class (inherits from both B and C)
    class D : public B, public C {
        // members of D
    };

    int main() {
        D obj;
        // function calls using obj
        return 0;
    }



3. First Try on Inheritance
---------------------------
Example:
    class Animal {
    public:
        void eat() {
            cout << "Eating...";
        }
    };

    class Dog : public Animal {
    public:
        void bark() {
            cout << "Barking...";
        }
    };

    int main() {
        Dog d;
        d.eat();   // inherited
        d.bark();  // own
    }

4. Protected Members
--------------------
- Protected members of a class can be accessed in derived classes but not outside.

Example:
    class Base {
    protected:
        int x;
    };

    class Derived : public Base {
    public:
        void setX(int val) { x = val; }
    };


5. Base Class Access Specifiers
-------------------------------
- The access specifier determines how the base class members are inherited:

| Inheritance Type | public members | protected members | private members |
|------------------|----------------|-------------------|-----------------|
| public           | public         | protected         | not accessible  |
| protected        | protected      | protected         | not accessible  |
| private          | private        | private           | not accessible  |


6. Private Inheritance
----------------------
- Public and protected members of base become private in derived.

Example:
    class A {
    public:
        void show() { cout << "A"; }
    };

    class B : private A {
    public:
        void callShow() { show(); }
    };

    int main() {
        B obj;
        obj.callShow();
        return 0;
    }


7. Resurrecting Members using 'using'
-------------------------------------
- You can make inherited private/protected members accessible using:
    using Base::member;

    class A {
    protected:
        void show() {
            cout << "A's show function" << endl;
        }
    };

    class B : protected A {
    public:
        // Make A's show() accessible publicly in B
        using A::show;
    };

    int main() {
        B obj;
        obj.show();  // Allowed because 'show' is now public in B
        return 0;
    }

8. Constructors in Inheritance
------------------------------

Default Constructor Call:
    class Base {
    public:
        Base() { cout << "Base"; }
    };

    class Derived : public Base {
    public:
        Derived() { cout << "Derived"; }
    };

    int main() {
        Derived d; // BaseDerived
    }


Constructor with Parameters:
    class Base {
    public:
        Base(int x) { cout << x; }
    };

    class Derived : public Base {
    public:
        Derived() : Base(10) {}
    };

    int main() {
       Derived d; // 10
    }

Copy Constructor:
    class Base {
    public:
        Base(const Base& b) { cout << "BaseCopy"; }
    };

    class Derived : public Base {
    public:
        Derived(const Derived& d) : Base(d) { cout << "DerivedCopy"; }
    };

    int main() {
        Derived d1 = d1;  // Copy constructor call 
        // BaseCopyDerivedCopy
    }


Inheriting Constructors:
    class Base {
    public:
        Base(int x) { cout << "Base:" << x; }
    };

    class Derived : public Base {
    public:
        using Base::Base;  // Inherit constructors
    };

    int main() {
        Derived d(100); //Base:100
    }


9. Virtual Destructors
----------------------
- Base class destructor should be virtual to allow proper cleanup.

    class Base {
    public:
        virtual ~Base() { cout << "Base Destructor"; }
    };


10. Member Hiding
-----------------
- Derived class members can hide base class members with the same name.
- Use Base::member to access hidden members.

    class Base {
    public:
        void display() { cout << "Base"; }
    };

    class Derived : public Base {
    public:
        void display() { cout << "Derived"; }
    };

    int main() {
        Derived d;
        d.display();         // Calls Derived version
        d.Base::display();   // Calls Base version
    }


11. Summary Table
-----------------

| Feature                   | Description                                |
|---------------------------|--------------------------------------------|
| Inheritance Types         | Single, Multiple, Multilevel, Hierarchical, Hybrid |
| Base Access Control       | Affects access to inherited members        |
| Constructor Order         | Base → Derived                             |
| Destructor Order          | Derived → Base (reverse)                   |
| Copy Constructor          | Must explicitly call base copy constructor |
| using keyword             | Re-expose inherited members                |
| Virtual Destructor        | Ensures safe cleanup in polymorphism       |
| Member Hiding             | Handled using Base::member                 |



Detailed Notes on Polymorphism in C++
==========================================
1. Introduction to Polymorphism
-------------------------------
Polymorphism means 'many forms'. In programming, it refers to the ability of a function, operator, or object to behave differently based on the context.

Types:
- Compile-time Polymorphism (function overloading, operator overloading)
- Run-time Polymorphism (virtual functions and method overriding)

1. Compile-time Polymorphism
    Also called Static Polymorphism, it is resolved during compilation.

    A. Function Overloading
        Same function name with different parameter types or counts.
        class Print {
        public:
            void show(int a) {
                cout << "Integer: " << a << endl;
            }

            void show(double b) {
                cout << "Double: " << b << endl;
            }

            void show(string s) {
                cout << "String: " << s << endl;
            }
        };

        int main() {
            Print p;
            p.show(10);         // Integer: 10
            p.show(3.14);       // Double: 3.14 
            p.show("Hello");    // String: Hello
            return 0;
        }

    B. Operator Overloading
        Operators are redefined for user-defined types (classes).
        class Complex {
            int real, imag;
        public:
            Complex(int r = 0, int i = 0) : real(r), imag(i) {}

            // Overload + operator
            Complex operator+(const Complex& other) {
                return Complex(real + other.real, imag + other.imag);
            }

            void display() {
                cout << real << " + " << imag << "i" << endl;
            }
        };

        int main() {
            Complex c1(3, 2), c2(1, 4);
            Complex c3 = c1 + c2;  // Calls overloaded +
            c3.display();       // 4 + 6i 
            return 0;
        }

2. Run-time Polymorphism
    Also called Dynamic Polymorphism, resolved at runtime using virtual 
    functions and method overriding.

    Virtual Functions and Method Overriding
    class Animal {
    public:
        virtual void sound() {
            cout << "Animal sound" << endl;
        }
    };

    class Dog : public Animal {
    public:
        void sound() override {
            cout << "Bark" << endl;
        }
    };

    class Cat : public Animal {
    public:
        void sound() override {
            cout << "Meow" << endl;
        }
    };

    int main() {
        Animal* a;
        Dog d;
        Cat c;

        a = &d;
        a->sound();  // Outputs: Bark (runtime resolution)

        a = &c;
        a->sound();  // Outputs: Meow

        return 0;
    }

Polymorphism promotes code reusability and scalability.

Example:
    int add(int a, int b) { return a + b; }
    float add(float a, float b) { return a + b; }

This is compile-time polymorphism.


2. Static Binding with Inheritance
----------------------------------
In static binding, the method to be called is determined at compile-time based on the pointer type.

Example:
    class Base {
    public:
        void display() { cout << "Base class"; }
    };

    class Derived : public Base {
    public:
        void display() { cout << "Derived class"; }
    };

    int main() {
        Base* ptr = new Derived();
        ptr->display();  // Output: Base class
    }

Explanation: Though the object is Derived, pointer is of type Base, and display() is not virtual — so Base’s method is called.


3. Dynamic Binding with Virtual Functions
-----------------------------------------
Dynamic binding means the method call is resolved at runtime using virtual functions.

Example:
    class Base {
    public:
        virtual void display() { cout << "Base"; }
    };

    class Derived : public Base {
    public:
        void display() override { cout << "Derived"; }
    };

    int main() {
        Base* ptr = new Derived();
        ptr->display();  // Output: Derived
    }

Explanation: Because `display()` is virtual, runtime polymorphism allows Derived’s method to be called.


4. Size of Polymorphic Objects and Slicing
------------------------------------------
When a derived object is assigned to a base object, additional data in the derived class gets sliced.

Example:
    class A { int x; };
    class B : public A { int y; };

    A obj = B();  // Only A's part is copied

Explanation: This can lead to unexpected results and object slicing problems.


5. Polymorphic Objects Stored in Arrays
---------------------------------------
Polymorphism allows storing pointers to base class in arrays and calling derived class methods via virtual functions.

Example:
    class Animal {
    public:
        virtual void sound() { cout << "Some sound"; }
    };

    class Dog : public Animal {
    public:
        void sound() override { cout << "Bark"; }
    };

    class Cat : public Animal {
    public:
        void sound() override { cout << "Meow"; }
    };

    int main() {
        Animal* a[2];
        a[0] = new Dog();
        a[1] = new Cat();
        a[0]->sound();  // Bark
        a[1]->sound();  // Meow
    }


6. Override
-----------
Used to ensure that a function actually overrides a virtual function from the base class.

Example:
    class Parent {
    public:
        virtual void greet() {}
    };

    class Child : public Parent {
    public:
        void greet() override {}  // Correct
    };

If override is missing and signature mismatches, the compiler won't detect the mistake.


7. Overloading, Overriding and Function Hiding
----------------------------------------------
Overloading: Same function name, different parameters.
Overriding: Derived class defines the same method as base with same signature.
Function Hiding: Derived function hides all overloads of the base.

Example of hiding:
    class A {
    public:
        void show(int x) { cout << x; }
    };

    class B : public A {
    public:
        void show() { cout << "B"; }
    };

    B b;
    b.show();       // Calls B::show()
    // b.show(10);  // Error unless `using A::show;` is added


8. Inheritance and Polymorphism at Different Levels
----------------------------------------------------
Virtual functions can be overridden at multiple inheritance levels.

Example:
    class A {
    public:
        virtual void show() { cout << "A"; }
    };

    class B : public A {
    public:
        void show() override { cout << "B"; }
    };

    class C : public B {
    public:
        void show() override { cout << "C"; }
    };

    A* obj = new C();
    obj->show();  // Output: C


9. Inheritance and Polymorphism with Static Members
----------------------------------------------------
Static members are class-level, not object-level, and hence not polymorphic.

Example:
    class Base {
    public:
        static void print() { cout << "Base"; }
    };

    class Derived : public Base {
    public:
        static void print() { cout << "Derived"; }
    };

    Base::print();     // Base
    Derived::print();  // Derived


10. Final
---------
Prevents overriding or further inheritance.

Example:
    class A final {};  // Cannot be inherited

    class Base {
    public:
        virtual void run() final;
    };

    class Derived : public Base {
        // void run();  // Error: cannot override final function
    };


11. Virtual Functions with Default Arguments
--------------------------------------------
Default values are resolved at compile-time, not run-time.

Example:
    class A {
    public:
        virtual void f(int x = 1) { cout << x; }
    };

    class B : public A {
    public:
        void f(int x = 2) override { cout << x; }
    };

    A* obj = new B();
    obj->f();  // Output: 1 (not 2)


12. Virtual Destructors
-----------------------
Ensures derived destructors are called when deleting via base pointer.

Example:
    class Base {
    public:
        virtual ~Base() { cout << "Base destroyed"; }
    };

    class Derived : public Base {
    public:
        ~Derived() { cout << "Derived destroyed"; }
    };

    Base* b = new Derived();
    delete b;  // Calls both destructors


13. Dynamic Casts
-----------------
Performs safe downcasting.

Example:
    class A {
    public:
        virtual void test() {}
    };

    class B : public A {
    public:
        void child() {}
    };

    A* base = new B();
    B* derived = dynamic_cast<B*>(base);
    if (derived)
        derived->child();

14. Polymorphic Functions and Destructors
-----------------------------------------
When a class has virtual functions, the destructor must be virtual.
Otherwise, only base destructor is called, causing memory leaks.

15. Pure Virtual Functions and Abstract Classes
-----------------------------------------------
A pure virtual function has no body in base class. Declared using `= 0`.

Example:
    class Shape {
    public:
        virtual void draw() = 0;  // pure virtual
    };

    class Circle : public Shape {
    public:
        void draw() override { cout << "Circle"; }
    };

Shape* s = new Circle();
s->draw();  // Output: Circle


16. Abstract Classes as Interfaces
----------------------------------
If a class contains only pure virtual functions, it is treated like an interface.

Example:
    class Printable {
    public:
        virtual void print() = 0;
    };

    class Report : public Printable {
    public:
        void print() override { cout << "Report"; }
    };

- In C++, collections are primarily provided through the Standard Template Library (STL).
- In C++, these are mostly implemented using the **Standard Template Library (STL)**.

Main STL Components:
---------------------
1. Containers
2. Iterators

3. STL Containers (Collections)
-------------------------------
STL (Standard Template Library) provides ready-to-use collections like:

    vector (dynamic array)
    list (doubly linked list)
    deque (double-ended queue)
    stack (LIFO)
    queue (FIFO)
    map (key-value pair, sorted)
    unordered_map (key-value pair, not sorted)
    set (unique elements)
    unordered_set (faster, not sorted)

    #include <iostream>
    #include <vector>
    #include <list>
    #include <deque>
    #include <stack>
    #include <queue>
    #include <map>
    #include <set>
    #include <unordered_map>
    #include <unordered_set>
    using namespace std;

    int main() {

        // ===== VECTOR =====
        vector<int> v = {1, 2, 3};
        v.push_back(4);   // Add at end
        cout << "Vector: ";
        for (int x : v) cout << x << " ";
        cout << endl;

        // ===== LIST =====
        list<string> names = {"Alice", "Bob"};
        names.push_front("Zara");
        names.push_back("John");
        cout << "List: ";
        for (string s : names) cout << s << " ";
        cout << endl;

        // ===== DEQUE =====
        deque<int> dq;
        dq.push_front(10);
        dq.push_back(20);
        dq.push_front(5);
        cout << "Deque: ";
        for (int x : dq) cout << x << " ";
        cout << endl;

        // ===== STACK =====
        stack<char> st;
        st.push('A');
        st.push('B');
        st.push('C');
        cout << "Stack (top to bottom): ";
        while (!st.empty()) {
            cout << st.top() << " ";
            st.pop();
        }
        cout << endl;

        // ===== QUEUE =====
        queue<string> q;
        q.push("One");
        q.push("Two");
        q.push("Three");
        cout << "Queue (front to back): ";
        while (!q.empty()) {
            cout << q.front() << " ";
            q.pop();
        }
        cout << endl;

        // ===== MAP =====
        map<int, string> m;
        m[1] = "One";
        m[2] = "Two";
        m[3] = "Three";
        cout << "Map (sorted by key): ";
        for (auto p : m) {
            cout << "[" << p.first << ":" << p.second << "] ";
        }
        cout << endl;

        // ===== UNORDERED MAP =====
        unordered_map<string, int> umap;
        umap["apple"] = 5;
        umap["banana"] = 10;
        umap["cherry"] = 2;
        cout << "Unordered Map: ";
        for (auto p : umap) {
            cout << "[" << p.first << ":" << p.second << "] ";
        }
        cout << endl;

        // ===== SET =====
        set<int> s = {5, 1, 2, 2, 4};  // duplicates ignored
        cout << "Set (sorted unique): ";
        for (int x : s) cout << x << " ";
        cout << endl;

        // ===== UNORDERED SET =====
        unordered_set<string> uset = {"A", "B", "A", "C"};
        cout << "Unordered Set (unique, unordered): ";
        for (auto x : uset) cout << x << " ";
        cout << endl;

        return 0;
    }

    Output
    Vector: 1 2 3 4
    List: Zara Alice Bob John
    Deque: 5 10 20
    Stack (top to bottom): C B A
    Queue (front to back): One Two Three
    Map (sorted by key): [1:One] [2:Two] [3:Three]
    Unordered Map: [banana:10] [apple:5] [cherry:2]
    Set (sorted unique): 1 2 4 5
    Unordered Set (unique, unordered): A B C

| Collection      | Characteristics                     | Use Case                                    |
| --------------- | ----------------------------------- | ------------------------------------------- |
| `vector`        | Dynamic array, fast index access    | Store sequence of values with random access |
| `list`          | Doubly linked list                  | Fast insert/delete in middle                |
| `deque`         | Insert/delete from both ends        | Double-ended queue                          |
| `stack`         | Last-In-First-Out (LIFO)            | Function call tracking, undo operations     |
| `queue`         | First-In-First-Out (FIFO)           | Order processing                            |
| `map`           | Sorted key-value pairs              | Phone book, dictionary                      |
| `unordered_map` | Faster key-value store (hash table) | Lookup tables where order doesn’t matter    |
| `set`           | Unique sorted values                | Remove duplicates and keep order            |
| `unordered_set` | Unique values, unordered            | Fast lookups, e.g., word filters            |
