MappedBy signals hibernate that the key for the relationship is on the other side.

This means that although you link 2 tables together, only 1 of those tables has a foreign key constraint to the other one.

@Entity
public class Answer 
{
	@ManyToOne
	private Question question;
}

@Entity
public class Question 
{
@OneToMany(cascade=CascadeType.ALL,mappedBy="question")
	private List<Answer> ans;
}

in the above example, inside Question class,

@OneToMany(cascade=CascadeType.ALL,mappedBy="question")
	private List<Answer> ans;

tells hibernate that the key for the relationship is on the Answer table side.

i.e.  tables will be created as follows:
