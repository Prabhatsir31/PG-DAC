@Entity
public class Question 
{
	@OneToMany(cascade=CascadeType.ALL,mappedBy="question")
	private List<Answer> ans;

	
}

@Entity
public class Answer 
{
	@ManyToOne
	private Question question;
}

"mappedBy" is required in "bi-directional" relationship.

Here we have One to Many bi-directional relationship. It means not only from Question we can retrieve its answers but also from a particular Answer we can retrieve its Question.


if we don't mention 
	mappedBy="question"

Hibernate creates an additional table

	+--------------+-----------+
	|            1 |         1 |
	|            1 |         2 |
	|            1 |         3 |

	3 rows in set (0.00 sec)



public class Question 
{
	@OneToMany(cascade=CascadeType.ALL,mappedBy="question")
	private List<Answer> ans;

	
}

@Entity
public class Answer 
{
	@ManyToOne
	private Question question;
}

here , mappedBy="question" tells Hibernate that not to create association table rather @ManyToOne side (Answer table) is in charge of managing the Foreign Key column i.e. "question_qid" additional column in Answer table. "qid" is 

	@Id
	@GeneratedValue(strategy=GenerationType.IDENTITY)
	private int qid;

inside "Question" class.


The mappedBy attribute characterizes a bidirectional association and must be set on the parent-side (Question class). In other words, for a bidirectional @OneToMany association, set mappedBy to @OneToMany on the parent-side (Question class) and add @ManyToOne on the child-side (Answer class) referenced by mappedBy . i.e.

in Question class (Parent class)

public class Question 
{
	@OneToMany(cascade=CascadeType.ALL,mappedBy="question")
	private List<Answer> ans;
}

and in Answer class (Child class)

@Entity
public class Answer 
{
	@ManyToOne
	private Question question;
}

so tables will be created as follows:

You started with ManyToOne mapping ( in Answer class)  , then you put OneToMany mapping ( in Question class ) as well for BiDirectional way. Then at OneToMany side (usually your parent table/class i.e. Question class ), you have to mention "mappedBy" (mapping is done by and in child table/class i.e. Answer class), so hibernate will not create EXTRA mapping table in DB (like TableName = parent_child  e.g.  Question_Answer).
