	getUsernameFromToken: Calls getClaimFromToken to retrieve a specific claim (the username, which is the subject of the JWT).

getClaimFromToken: A generic method that allows extraction of any claim from the JWT by calling getAllClaimsFromToken and applying a function to the claims (like Claims::getSubject, Claims::getExpiration, etc.).

getAllClaimsFromToken: The low-level method that decodes the JWT and extracts all claims using the secret key for validation.

Each method builds on the previous one to provide a flexible and reusable way of extracting information from a JWT.
