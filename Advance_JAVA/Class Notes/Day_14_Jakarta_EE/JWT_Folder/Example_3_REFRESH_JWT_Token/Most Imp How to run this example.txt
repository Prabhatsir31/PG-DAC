1) run your spring boot application
	you will notice that it creates a table "refresh_tokens" for the first time

mysql> desc refresh_tokens;

4 rows in set (0.01 sec)


2) go to postman and type "http://localhost:8080/token"

select "POST"

raw
body
	
	{
	    "username":"master",
	    "password":"master123"
	}
		or
	{
	    "username":"scott",
	    "password":"tiger"
	}

this is because we've already created 2 users in the database.
click on "send"
this will give you following output for example:


{
    "token": "eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiJzY290dCIsImlhdCI6MTcwMDYzOTY2NCwiZXhwIjoxNzAwNjM5Nzg0fQ.aIfoTxqEJX-NHm5IaoqJhZJMFCFeqgnedcuLCEh_wn8",
    "refreshtoken": "166294f9-2efc-4576-8760-485b2d1688a8"
}

notice here that we are getting two tokens:
	a) JWT token
	b) refreshtoken

go to database and check:
	select * from refresh_tokens;
	you will notice that the record which represents this refresh token gets created and that too for a particular user [ scott or master].


in the example we have set expiry time for JWT token as 2 minutes and for refresh token as 10 minutes.

now copy above JWT token and refresh token to a notepad.

to check the expiration times for both these tokens, keep two tabs open on browser
	a) jwt.io
		here you copy entire JWT generated inside "Encoded" section and notice the expiry time.
	b) google.com
		go to MySQL and type
			select * from refresh_tokens;
	you will see refresh_token here
	just copy the value of "expiry" column say e.g. "08:04" and go to google and type:
	08:04  UTC time
		you will get the local time which is the expiry time for the generated refresh token.


go to postman and type


http://localhost:8080/hello

select "GET"
	inside "Headers"
		key    -   Authorization
		value - Bearer   <jwt token generated>
click on "send"
	make sure you get "Hello World" as an output.
click on "send" for next 2 minutes you will get the  same output.
After 2 minutes when u click on "send" , u will get exception
"ExpiredJWTException" [ as expiry of you JWT token is 2 minutes]

now you need not log in again to get JWT token [ which is the key benefit of Refresh token]

go to postman and type

http://localhost:8080/refresh
	select "POST"
raw
body
	type
		{
			"refreshtoken":"<generated refreshtoken>"
		}
click on "send"

make sure it gives you
	new JWT token and
	existing refresh token

now for next 2 minutes 
	http://localhost:8080/hello
		GET
	Headers
		key - Authorization
		value - generated new JWT token

again after 2 minutes newly generated token will be expired.
now again
	http://localhost:8080/refresh
		POST
	raw
	body
		{
			"refreshtoken":"generated refreshtoken"
		}

you will get
	new JWT token and
	existing refresh token

this will go on for 10 minutes as refresh token's life is for 10 minutes.

after 10 minutes when you do:

http://localhost:8080/refresh
		POST
	raw
	body
		{
			"refreshtoken":"generated refreshtoken"
		}

you will not get any thing rather an exception saying
	refresh token expired.

go to database and check:
	select * from refresh_tokens;
	you will notice that the record which represents this refresh token gets deleted from this table.
