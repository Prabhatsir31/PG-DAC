If you want to perform custom actions before the form submits—like validating data, showing a loading indicator, or making an AJAX request—you need to call e.preventDefault() to stop the form submission from reloading the page.

In JavaScript, when you're handling a form submission (or any other event), sometimes you don't want the default action to take place. Instead, you want to handle the event yourself.

For example:

Form Submission: Normally, when a user submits a form, the browser sends the form data to the server, and the page is reloaded. If you don't want the page to reload and instead want to handle the submission via AJAX (sending data in the background without refreshing), you need to prevent the form's default action.

Understanding e.preventDefault();
In JavaScript, when you interact with elements on a webpage—like submitting a form, clicking a button, or clicking a link—there is usually some default behavior associated with those actions. For example:

When you submit a form, the default behavior is that the form's data is sent to the server, and the page is reloaded.
When you click a link, the default behavior is that the browser navigates to the URL specified in the link.
When you click a button (that doesn't have a type="submit"), nothing happens unless you define behavior using JavaScript.
e.preventDefault(); is a method that prevents the default action associated with the event from happening.
