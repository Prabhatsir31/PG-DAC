first time you have to run the application in order to get the token

go to browser and type


http://localhost:8080/login

form will appear which will accept "username" and "password"


click on "submit"


it displays "welcome.html" with the token sent by REST controller

copy paste this token on some notepad


second time, go to postman and type:

	http://localhost:8080/hello
		method  Get
	header
		Authorization
			value
			Bearer<space>token which was generated in the last request

make sure it works and gives you the output.
