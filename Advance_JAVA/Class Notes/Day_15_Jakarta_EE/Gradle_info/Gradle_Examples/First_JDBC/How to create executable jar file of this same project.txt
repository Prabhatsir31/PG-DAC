Create a Runnable JAR File

If your project has a main class and you want the JAR to be executable:

But this jar file should contain all the dependencies (MySQL connector jar in our example) u have included inside "build.gradle" file, otherwise executable jar file won't get dependencies.
For this purpose we have to create fat jar file.

make sure your "build.gradle" file looks like following:



plugins {
    id 'java-library'
    id 'java'
    id 'application'
    id 'com.github.johnrengelman.shadow' version '8.1.1'
}

repositories {
    mavenCentral()
}

tasks.jar {
    manifest {
        attributes(
            'Main-Class': 'gradle_pro.App1' // Replace with your main class
        )
    }
}

dependencies {
    // Use JUnit Jupiter for testing.
    testImplementation 'org.junit.jupiter:junit-jupiter:5.8.1'

    // This dependency is exported to consumers, that is to say found on their compile classpath.
    api 'org.apache.commons:commons-math3:3.6.1'

    // This dependency is used internally, and not exposed to consumers on their own compile classpath.
    implementation 'com.google.guava:guava:30.1.1-jre'
    implementation 'mysql:mysql-connector-java:8.0.29'
}

application {
    mainClass = 'gradle_pro.App1' // Replace with your main class
}

tasks.named('shadowJar') {
    archiveBaseName.set('jdbc_app_1') // Set the base name for the JAR
    archiveVersion.set('1.0.0')          // Set the version (optional)
    archiveClassifier.set('')            // Remove the '-all' classifier
    manifest {
        attributes(
            'Main-Class': 'gradle_pro.App1' // Replace with your main class
        )
    }
}

tasks.named('test') {
    // Use JUnit Platform for unit tests.
    useJUnitPlatform()
}



save above "build.gradle"
