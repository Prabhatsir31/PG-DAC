Serialization (Python to Java) involves converting Python native data structures into JSON format and sending them over HTTP. Deserialization (Java) is the process of converting JSON data received over HTTP back into Java objects using Jackson in your Spring Boot application. 

Spring Boot includes Jackson as part of its auto-configuration setup. 

Automatic Configuration: Spring Boot automatically configures Jackson for JSON (de)serialization by default. This means you don't need to explicitly configure jackson dependency.

Field Matching: Jackson uses reflection to map JSON properties to Java object fields by default. If the field names in your Java class (Person in your case with "name","age" and "address" field names) match the keys in the JSON payload, i.e.
		{
  			"name":"Ram",
 			"age":65,
  			"address":"Delhi"
		}

Jackson can map them automatically.


Default Constructor: Jackson requires a default (no-argument) constructor to instantiate objects during deserialization. In our example Person class has a default constructor (public by default), which is sufficient for Jackson to create instances of Person.

Getter and Setter Methods: While getters and setters are not strictly necessary for Jackson to work (it can use fields directly if they are accessible), having them improves readability and maintainability of your code.
